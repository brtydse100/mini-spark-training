# Mini Spark Exercise

There are three separate folders:

1. **Package** is Workframe, a normal Python library: source, metadata,
   documentation, generic examples, tests, setup/build scripts, and benchmarks.
2. **Exercise** contains the actual assignment, stages, Excel tables, JSON
   schemas, data generator, and application starter. Trainees build their engine
   here while using and investigating Workframe.
3. **Instructor Guide** contains answers, setup notes, defect explanations,
   reference tools, and assessment guidance. Keep this folder for yourself.

Start with [the instructor index](Instructor%20Guide/00%20-%20START%20HERE.md),
then [setup](Instructor%20Guide/02%20-%20Setup.md).

Library code: Package/src/workframe. Trainee application: Exercise/starter.
The application driver starts unimplemented; Workframe's generic examples run
independently. CPU/memory control and the timer are library facilities.
